# Spec Review playground

Fictional specifications for testing the ONVIF Spec Review application. Nothing here is an ONVIF standard or a production requirement.

Use the demo pull request to try:

- A PR summary, a file note, and a comment on an individual rendered change.
- Marking changes reviewed and navigating between files.
- Suggested changes to exact XML/source lines, and applying suggestions on GitHub.
- Backup/import, and refreshing after another commit changes the PR.

All branches, reviews and suggestions here are disposable test data. Comment reviews on your own PR are supported; GitHub does not let authors approve their own PRs.
